# Vegetation & Forest Cover Change in Ngong Road Forest (2018–2026)

Remote sensing analysis of vegetation and land-cover change in Ngong Road
Forest, Nairobi, using Sentinel-2 (Google Earth Engine) and QGIS.

**Status:** In progress — Week 1: data setup.

## Research question
How has vegetation and forest cover in Ngong Road Forest changed between
2018 and 2026, and where is the loss concentrated?

## Repo structure
- `data/` — boundary + exported rasters (raw rasters not committed)
- `scripts/` — GEE export script and Python analysis
- `maps/` — final map layouts
- `outputs/` — tables and statistics (CSV)
